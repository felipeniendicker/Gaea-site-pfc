# GAEA — Site PFC

Site institucional do projeto acadêmico **Gestão e Acompanhamento de Estágios Acadêmicos**.

## Executar

```bash
npm install
npm run dev
```

## Publicar

Na Vercel, importe este repositório, selecione o framework **Vite** e publique. `vercel.json` permite acessar as rotas diretamente.

## Páginas

Início, Sobre, Funcionalidades, Como funciona, Demonstração e Equipe.

## Observações

A demonstração utiliza dados fictícios no navegador; não está integrada ao backend do PFC. O código deve ser revisado e testado antes da entrega.
